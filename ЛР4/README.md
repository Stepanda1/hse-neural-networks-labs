# ЛР4

Распознано 12 из 12 обучающих образов и 3 из 3 новых. Все снимки сделаны при повторном выполнении в тренажёре с русским интерфейсом.

Отчёт.pdf предназначен для чтения и отправки. Отчёт.docx является редактируемой копией. Папка Скриншоты содержит настоящие снимки программы; JSON и журналы содержат введённые данные, параметры и считанные результаты. Обучение и распознавание выполнены исходным тренажёром. Вспомогательный код управлял интерфейсом, сверял клетки и оформлял результаты.

Для повторения распакуйте папку целиком, откройте Программа/Start_LR4.cmd, введите данные и параметры из отчёта и JSON, затем выполните штатные обучение и проверку. Методичка находится в Программа/LR_HLP/4.pdf.

Отдельной команды сохранения новых обученных весов в интерфейсе LR1–LR7 нет. Поэтому приложены исходная программа, настройки, введённые данные и свидетельства выполнения. Файлы *.net.txt являются исходными файлами практикума, а не экспортом новых обученных весов. Новое обучение может дать другие непрерывные ответы из-за начальных весов.
