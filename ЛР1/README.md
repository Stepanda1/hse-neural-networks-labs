# ЛР1. Пороговый нейрон

В исходном LR1.exe проверены два набора параметров для И, два для ИЛИ и неудачная попытка XOR. Полные параметры приведены в Выполнение.json, решения разъяснены в отчёте.

Все снимки пересняты после расчёта с читаемым русским интерфейсом. Файлы 02 и 04 показывают подтверждение второго набора в протоколе справа. К моменту снимка программа уже переключила столбец d на следующую функцию, а столбец y ещё показывает вычисленный результат предыдущей. Снимки 01 и 03 показывают совпадение столбцов для И и ИЛИ, снимок 05 показывает ошибку XOR на паре 11.

Для повторения распакуйте папку и откройте Программа/Start_LR1.cmd. Методичка находится в Программа/LR_HLP/1.pdf.
