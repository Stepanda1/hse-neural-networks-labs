# ЛР8

В Нейросимуляторе обучены сети 2–2–1 и 2–7–1 по 5000 итераций. Ответы для исключённого 2×5 составили 9,5577 и 9,9234. Родные обученные NP4 сохранены.

Откройте Nsim5-10s.exe и загрузите нужный *_GUI.np4 кнопкой загрузки проекта. Эти проекты сохранены самой программой после обучения и вычисления ответов. Для нового обучения откройте файл с входными данными, проверьте архитектуру и таблицы, затем на вкладке Обучение нажмите Обучить заново. На вкладках Проверка и Прогноз нажмите Вычислить. Результат сохраняйте отдельным проектом.

Отчёт.pdf предназначен для чтения и отправки, DOCX для редактирования. Папка Данные содержит исходную таблицу, Результаты содержит извлечённые из сохранённых проектов ответы, Скриншоты содержит реальные снимки интерфейса. Ответы округлены программой до четырёх знаков; расчётные метрики относятся к этим значениям.
